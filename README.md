# おかしタワー・ドロップ 3D

ゲームセンターのプライズ機「トライポッド」をモチーフにした、ブラウザで遊べる3Dプライズゲームです。
ルーレットの光をタイミングよく止めてアームを下げ、積み上げられたお菓子や飲み物を穴に落として獲得します。

インストール不要で、`index.html` を開くだけで遊べます。

## あそびかた

1. **START** ボタン（100円）を押すと、リングのまわりを光が回り始めます
2. 光が **STOP の矢印** のマスにあるときに **STOP** を押します
3. 矢印の先のアームが下がり、上に乗った景品が崩れて穴に落ちれば獲得
4. 制限時間は **10秒**。時間切れになると、その場で自動ストップします
5. 台の景品を全部落とすと、**全部取るのにかかった金額** が表示されます

- 矢印のないマスや、もう下がったアームで止めるとハズレです
- タワーはわずかに傾いて積まれています。視点を回して、傾いている側のアームを狙うのがコツです
- 光の回る速さは、本物のゲーセンのように毎回ランダムです（設定で固定もできます）

### 操作

| 操作 | 内容 |
| --- | --- |
| START / STOP ボタン | 100円投入・ルーレットを止める |
| スペースキー / Enter | ボタンと同じ |
| ドラッグ | 視点を回す |
| ピンチ / ホイール | 拡大・縮小 |
| 視点ボタン | 斜め上・正面・真上・外観 に切り替え |

## 景品の種類

画面上のタブで切り替えられます。

| 景品 | 特徴 |
| --- | --- |
| カップ菓子 | スティック菓子のカップを積んだタワー |
| カップ麺 | 大きめのカップ麺のタワー |
| 箱のお菓子 | 箱菓子をレンガ積みにしたタワー |
| ペットボトル | 横に寝かせたペットボトルの山 |
| 缶ジュース | 缶を高く積んだタワー |
| コーンチョコの山 | コーン型チョコ菓子を放射状に積んだ山 |
| BIG筒 | 大きな筒を立てかけた一発勝負。下を支える2本のアームを両方下げると倒れます |

※ 商品名・パッケージはすべて架空のものです。

## 機能

- Three.js による実機風の3Dグラフィック（ゲーム機の外観つき）
- cannon-es による物理演算で、景品が崩れて落ちる様子を再現
- 制限時間（10秒）とカウントダウン表示
- 1台ごとのプレイ金額と残り景品数の表示
- 効果音（ON/OFF 切り替え可）
- 重心表示（狙いやすくするヒント）
- スマホ・PC 両対応のレイアウト

## 起動方法

### ローカルで遊ぶ

`index.html` をブラウザ（Chrome / Edge / Safari / Firefox の最新版）で開くだけです。

> Three.js と cannon-es を CDN（jsDelivr）から読み込むため、**インターネット接続が必要** です。

### GitHub Pages で公開する

1. このリポジトリを GitHub に push
2. リポジトリの **Settings → Pages** を開く
3. **Branch** を `main`、フォルダを `/ (root)` にして **Save**
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で遊べるようになります

## セーブデータ

最後に選んだ景品の種類などが、ブラウザの `localStorage`（キー：`okashiTowerDrop3Dv2`）に保存されます。
リセットしたい場合は、ブラウザの開発者ツールからこのキーを削除してください。

## 注意

- 実在のプライズ機をモチーフにした非公式の作品です。メーカーとは関係ありません。
- 実際のお金は一切かかりません。表示される金額はゲーム内の目安です。
- 物理演算の都合で、アームが全部下がっても景品が穴の上に残ることがあります。
